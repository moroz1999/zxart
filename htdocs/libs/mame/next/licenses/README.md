# NextZXOS licence bundle

The licence texts that must be **served alongside** the NextZXOS content in
`../nextzxos.zip` (and the pinned card it is generated from,
`../../build/tbblue.mmc.zip`).

The Next License requires its copyright and permission notice to travel with
every copy of the distribution, "together with ALL individual licenses of all
constituent parts", so these texts are served from `/libs/mamenextsam/next/licenses/`,
next to the content itself.

| File | Purpose |
|------|---------|
| `THE-NEXT-LICENSE.txt` | The umbrella licence (permission notice) for the content. |
| `NOTICES.txt` | Copyright, per-constituent licence mapping, corresponding-source links. |
| `AMSTRAD-ROM-PERMISSION.txt` | Amstrad's permission covering the Spectrum ROM images. |
| `GPL-3.0.txt` | Full GPLv3 text, for the FPGA core and firmware on the card. |

The distribution these come from, and what is and is not taken from it, are in
[../../README.md](../../README.md).
