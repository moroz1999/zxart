The machines this MAME build runs

Each page boots one machine from software/ with nothing of the site around it.

  • SAM Coupé — samcoupe, starts software/release.dsk
  • TSConf :: SPG — tsconf2, starts software/release.spg
  • TSConf :: TR-DOS — tsconf2, starts software/release.trd
  • TSConf :: SD card — tsconf2, starts software/release.img
  • Scorpion GMX :: SMUC :: NeoGS — scorpiongmx, starts software/release.trd
  • ATM Turbo 2+ — atmtb2plus, starts software/release.trd
  • Profi — profi, starts software/release.trd
  • ZX Evolution :: BaseConf — pentevo, starts software/release.trd
  • Sprinter Sp2000 — sprinter, starts software/sp_hdd_sys.chd
