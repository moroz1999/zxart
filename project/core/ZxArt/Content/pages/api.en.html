NB: Providing non-empty User Agent header with all requests is required. Otherwise you will be banned by IP instantly.

Common description

  1. API is publicly accessible via HTTP and JSON
  2. Information accuracy is not guaranteed, the information in database is constantly being cleaned/rechecked/added.
  3. Information copying/backing up/usage for other databases is totally encouraged
  4. API format is subject to change without notification

Request format

All parameters are passed in the path as name:value pairs separated by slashes, in any order:
https://zxart.ee/api/export:zxPicture/limit:10/order:date,desc/

Common parameters:

  • export - entity name queried from API. All filtering, limiting and sorting parameters are being applied to this list.
    Possible values:
    • author
    • authorAlias
    • group
    • groupAlias
    • zxProdCategory
    • zxProd
    • zxRelease
    • zxPicture
    • zxMusic
    • party
    • country
    • city
  • language - language code for all translatable information: titles of countries, cities, categories and tags.
    Possible values:
    • eng
    • rus
    • spa
  • start - number of the first required element from list. Zero by default.
  • limit - quantity of elements in list. 1000 by default.
  • order - sorting of the list, in the form order:field,direction. Direction is asc or desc, ascending by default. The special value order:rand returns the elements in random order. Sorting fields differ per entity and are listed in the entity's section below.
  • filter - filtering of the list, see the Filtering section below.

Response format

The response is a JSON object with the following keys:

  • responseStatus - success or fail
  • totalAmount - quantity of elements matching the filters, ignoring start and limit
  • start, limit - the values applied to this response
  • responseData - object containing one key per exported entity name, holding the list of elements

Empty values are omitted. A field equal to zero, to an empty string or to an empty list is not present in the element object at all, so a missing field must always be treated as an empty value.

start, limit and order are not applied to zxProdCategory, authorAlias, groupAlias, country and city. These entities are always returned as a complete list.

Filtering

  • filter:name=value - one filter with one value
  • filter:name=value1,value2 - one filter with several values, any of them matches
  • filter:name1=value1;name2=value2 - several filters, all of them are applied together
  • filter:name - switch filters are used without a value

A filter may belong to an entity other than the exported one. For example filter:authorId=2333 combined with export:zxPicture returns the pictures of that author. Such conversion is implemented for the following pairs only, and an unsupported pair silently returns the unfiltered list:

  • zxPicture filtered by author, party or zxProd filters
  • zxMusic filtered by author or party filters
  • zxProd filtered by author, zxPicture or zxRelease filters
  • zxRelease filtered by zxProd filters
  • author filtered by zxPicture, zxMusic or zxProd filters
  • authorAlias filtered by zxPicture or zxMusic filters
  • party filtered by zxPicture or zxMusic filters

External database codenames:

These codenames are used as the keys of the importIds field.

  • 3a - ZXAAA
  • dzoo - DemoZoo
  • pouet - Pouet.net
  • sc - Spectrum Computing or ZXDB
  • wos - World Of Spectrum
  • vt - Virtual TR-DOS
  • zxd - Demotopia
