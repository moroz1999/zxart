Внимание: во всех запросах обязательно передавать непустой заголовок User Agent. Иначе IP будет заблокирован незамедлительно.

Общее описание

  1. API общедоступен по HTTP и отдаёт JSON
  2. Точность информации не гарантируется, данные в базе постоянно чистятся, перепроверяются и дополняются.
  3. Копирование, резервирование и использование информации в других базах данных всячески приветствуется
  4. Формат API может измениться без предупреждения

Формат запроса

Все параметры передаются в пути в виде пар name:value, разделённых слэшами, в произвольном порядке:
https://zxart.ee/api/export:zxPicture/limit:10/order:date,desc/

Общие параметры:

  • export - имя сущности, запрашиваемой у API. Все параметры фильтрации, ограничения и сортировки применяются именно к этому списку.
    Возможные значения:
    • author
    • authorAlias
    • group
    • groupAlias
    • zxProdCategory
    • zxProd
    • zxRelease
    • zxPicture
    • zxMusic
    • party
    • country
    • city
  • language - код языка для всей переводимой информации: названий стран, городов, категорий и тегов.
    Возможные значения:
    • eng
    • rus
    • spa
  • start - номер первого нужного элемента списка. По умолчанию ноль.
  • limit - количество элементов в списке. По умолчанию 1000.
  • order - сортировка списка в виде order:поле,направление. Направление - asc или desc, по умолчанию по возрастанию. Специальное значение order:rand возвращает элементы в случайном порядке. Поля сортировки различаются у разных сущностей и перечислены ниже в разделе каждой сущности.
  • filter - фильтрация списка, см. раздел «Фильтрация» ниже.

Формат ответа

Ответ представляет собой JSON-объект со следующими ключами:

  • responseStatus - success или fail
  • totalAmount - количество элементов, подходящих под фильтры, без учёта start и limit
  • start, limit - значения, применённые к этому ответу
  • responseData - объект, содержащий по одному ключу на каждое имя экспортируемой сущности со списком элементов

Пустые значения не выводятся. Поле, равное нулю, пустой строке или пустому списку, вообще отсутствует в объекте элемента, поэтому отсутствующее поле всегда следует считать пустым значением.

Параметры start, limit и order не применяются к zxProdCategory, authorAlias, groupAlias, country и city. Эти сущности всегда возвращаются полным списком.

Фильтрация

  • filter:name=value - один фильтр с одним значением
  • filter:name=value1,value2 - один фильтр с несколькими значениями, подходит любое из них
  • filter:name1=value1;name2=value2 - несколько фильтров, применяются все вместе
  • filter:name - фильтры-переключатели используются без значения

Фильтр может относиться к сущности, отличной от экспортируемой. Например, filter:authorId=2333 вместе с export:zxPicture вернёт картины этого автора. Такое преобразование реализовано только для перечисленных ниже пар, а неподдерживаемая пара молча вернёт неотфильтрованный список:

  • zxPicture фильтруется фильтрами author, party и zxProd
  • zxMusic фильтруется фильтрами author и party
  • zxProd фильтруется фильтрами author, zxPicture и zxRelease
  • zxRelease фильтруется фильтрами zxProd
  • author фильтруется фильтрами zxPicture, zxMusic и zxProd
  • authorAlias фильтруется фильтрами zxPicture и zxMusic
  • party фильтруется фильтрами zxPicture и zxMusic

  • groupFirstLetter - первая буква названия
  • groupCity - ID городов
  • groupCountry - ID стран
  • groupSearch - текст, который ищется в названии

Псевдоним группы

Псевдоним группы - это альтернативное название группы.

Все псевдонимы групп:
https://zxart.ee/api/export:groupAlias/

Псевдоним группы с ID 176109:
https://zxart.ee/api/export:groupAlias/filter:groupAliasId=176109

Поля:

  • id
  • title - название псевдонима группы
  • url - URL на ZX-Art
  • dateCreated - таймстамп даты создания
  • dateModified - таймстамп даты изменения
  • startDate, endDate - период, когда группа использовала это название
  • groupId - ID родительской группы
  • importIds - ID, используемые для этого псевдонима группы в других базах данных

Фильтры:

  • groupAliasId - ID псевдонимов
  • groupAliasFirstLetter - первая буква названия
  • groupAliasSearch - текст, который ищется в названии

Демопати

Демопати или любое другое соревнование, на котором показывались работы.

Все демопати:
https://zxart.ee/api/export:party/filter:partyAll

Демопати с ID 2201:
https://zxart.ee/api/export:party/filter:partyId=2201

Поля:

  • id
  • title - название демопати
  • url - URL на ZX-Art
  • dateCreated, dateModified - отформатированные даты, а не таймстампы
  • city - название города
  • country - название страны
  • year - год проведения демопати

Поля сортировки:

  • title, date

Фильтры:

  • partyAll - все демопати
  • partyId - ID демопати
  • partyCity - ID городов
  • partyCountry - ID стран
  • partyOfItemType - выбирает демопати, на которых есть работы указанного типа: zxPicture, zxMusic, zxProd
  • partySearch - текст, который ищется в названии

Страна и город

Страны и города - это отдельные сущности. Их ID являются значениями фильтров authorCountry, authorCity, groupCountry, groupCity, partyCountry, partyCity и zxProdCountryId.

Все страны:
https://zxart.ee/api/export:country/

Все города:
https://zxart.ee/api/export:city/

Поля:

  • id
  • title - название на выбранном языке
  • url - URL на ZX-Art
