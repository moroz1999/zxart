# Main page

The main page is a set of content blocks the visitor arranges themselves. Blocks
can be reordered, switched off, and given their own size and thresholds. A
logged-in visitor's arrangement follows their account across devices; an
anonymous visitor's stays in the browser.

## The blocks

- **New programs, new pictures, new music** — what the archive gained recently.
  New programs also asks for a minimum rating and how far back a work's own year
  of release may reach, so the block stays about current work rather than about
  old work newly archived.
- **Best new demos, best new games** — a changing pick of well-rated works from
  this year and last.
- **Recent parties** — the demoparties that happened most recently.
- **Best pictures of the month, best tunes of the month** — the best-rated work
  added lately.
- **Latest added programs, latest added releases** — the newest arrivals,
  whenever they were made.
- **Support programs** — programs sold or asking for donations, so visitors who
  want to pay authors can find them.
- **Unvoted pictures, unvoted music** — work the visitor has not yet rated. These
  only mean anything for someone logged in.
- **Random good pictures, random good music** — a changing pick of the best-rated
  work.

## Arranging them

The arrangement is edited in one dialog: drag to reorder, switch off what is not
wanted, and set each block's own options. The dialog stays open until the
arrangement has been saved, so a failure never looks like a success. Reset puts
everything back to the defaults.

A block the visitor has never seen keeps its default place, so blocks added later
appear rather than staying hidden.

## Catalogue front pages

The graphics and music sections have a front page of their own, built from the
same blocks: what was newly added, what the visitor has not rated, and the best
of the month.
