# Social posting

Newly added pictures, tunes, productions and releases are announced in the site's
Telegram channel, so the channel reads as a feed of what the archive gained.

An announcement carries the work's title, its description and a link back to its
page. A picture or a tune also names its authors beside the title. A tune is
posted as playable audio, a work with a picture as that picture, and anything
else as text.

Not everything is announced. A production without an image is skipped, and so is
a release when neither it nor its production has one — an announcement nobody can
look at is not worth sending. A release is also skipped when its production is
being announced in the same run or is still waiting to be, so one work does not
arrive twice.

The description is the same text the site shows on the work's own page.
