## Tags

A tag is a word a visitor attaches to a picture, a tune or a production to say
what it is about. Tags are shared across the archive, so the same word gathers
works of every kind.

### Tag cloud
Graphics, music and software each have a cloud of the tags used in that section.
A tag's size in the cloud follows how often it is used there, so the shape of a
section is visible at a glance.

The cloud can show every tag that is used at all, or only the tags that carry
some weight — at least 3, 5 or 10 works. It opens on 3, because a cloud of
one-off tags says nothing.

### Browsing a tag
Picking a tag opens the works carrying it, within the section the visitor came
from: a tag under graphics lists pictures, the same tag under music lists tunes.
Those pages can be ordered by name, rating and date added.

The tags shown on a work's own page lead to the same place, staying in that
work's section.

A tag page names itself after what it lists — for example: Pictures tagged
"Example" — and that wording is what a search engine and a shared link show.
