# Playlists

A playlist is a visitor's personal collection of works — pictures, tunes and
productions gathered under a name they chose. Every playlist belongs to exactly
one visitor; there are no shared or public playlists, and nobody but the owner
sees theirs.

A playlist is created, renamed and deleted from the playlists page, which shows
each one with how many pictures, tunes and productions it holds. Deleting a
playlist asks for confirmation and removes only the collection — the works it
pointed at stay in the archive.

Works are added to and removed from a playlist from the work itself, through the
same list of the visitor's playlists, so a new playlist can be started while
looking at the work that belongs in it.
