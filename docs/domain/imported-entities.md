# Entities imported from other portals

Much of the archive was brought in from other ZX Spectrum and demoscene sites.
An entity that came from such a portal remembers where it came from: the portal
itself and the identifier the entity has there. Productions, releases, authors,
author aliases, groups and group aliases all carry these pairs.

The pair is what the outgoing links on an entity page are built from — the page
on Spectrum Computing, Virtual TR-DOS, Pouet.net, Demozoo, Demotopia,
zxaaa.net, Speccy Screenshot Maps, spectrum4ever.org, World Of Sam, TS-Labs,
ZX Press or The RZX Archive that describes the same work or person. It is also
what a later import round uses to recognise an entity it has already seen, so
re-running an import updates the entity instead of creating a second one.

One entity may carry several identifiers on the same portal — a work published
there more than once — and identifiers on any number of portals. Which portals
actually produce a visible link differs per entity: an author links to the sites
that have people pages, a release to the sites that publish files.

Whoever may edit an entity may also correct these identifiers on its form: add a
missing one, point one at the right page, or drop one that turned out to be
wrong. Removing the last identifier of a portal simply removes that link from
the page.
