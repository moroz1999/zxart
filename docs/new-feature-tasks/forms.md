В папке forms/Entity Forms.dc.html лежит макет форм для создания и редактирования сущностей. 
Имплементируй этот макет с применением к реальным формам, которые готовы сейчас в черновом виде, но требуют красоты и доводки.

1. Опирайся на имеющийся компонент формы для layout. Для двух колонок можно его расширить через новый prop.
2. В макете есть стилизованные элементы всяких поисков, селекторов, ролей авторов и прочего. Те, что уже есть - переделай по макету. Те, которых нет - заведи с нуля как универсальные единицы и используй их повторно в разных сущностях, не дублируй.
3. Проанализируй макет и задай вопросы, если что-то не понятно или противоречиво.
4. Из всего этого сделай подробнейший пошаговый план - какие компоненты надо дополнить и чем. Какие по-новому написать. Какие формы надо обновить. 
5. В конце работы запусти агента для сверки с нашими md файлами.
